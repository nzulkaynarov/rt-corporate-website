# Дизайн сайта railtech.uz — стиль «Мост»
Статус: действует · Обновлено: 2026-11-04 · Макеты: https://claude.ai/artifact/1jRR1X7De7xGTigEzjyXWH

Стиль продолжает презентацию RailTech для партнёров: белый воздух, тёмно-синий текст, бирюзовый ромб логотипа,
оранжевые точки-акценты. Новые элементы берут значения только из токенов ниже (`src/styles/tokens.css`).

## Токены

| Токен | Значение | Где |
|---|---|---|
| `--c-bg` | `#FFFFFF` | фон страницы |
| `--c-soft` | `#F4F7F9` | фон чередующихся секций |
| `--c-ink` | `#2D3E50` | текст, основные кнопки, тёмные полосы |
| `--c-ink-deep` | `#1F2E3D` | футер, наведение на основные кнопки |
| `--c-muted` | `#5A6876` | вторичный текст (контраст 5,9:1 на белом) |
| `--c-line` | `#DDE5EA` | границы, разделители |
| `--c-brand` | `#35819B` | логотип и крупная графика (не для мелкого текста: 4,5:1 не проходит) |
| `--c-brand-ink` | `#2A6F86` | ссылки и мелкий бирюзовый текст (5,3:1) |
| `--c-brand-soft` | `#E3F0F4` | плашки, статус «официальный дилер», заглушки фото |
| `--c-accent` | `#E8833A` | только декор: точки, верхние линии карточек; текст этим цветом не пишем |
| `--c-on-ink` | `#FFFFFF` / `--c-on-ink-muted` `#B9C6D1` | текст на тёмно-синем |

Шрифты (своими файлами из пакетов `@fontsource`, без Google Fonts — сайт не обращается к сторонним серверам):
**Montserrat** 600/700/800 — заголовки, кнопки, цифры; **Golos Text** 400/500/600 — текст и интерфейс.
Моноширинный шрифт не используем. Шкала: 58/46/34 (H1 desktop/tablet/phone), 40/30 (H2), 22/19 (H3), текст 17/16.

Скругления: 6 px кнопки и поля, 8 px карточки, 999 px «таблетки». Тени только на всплывающих карточках при наведении.

## Компоненты

- **Кнопки:** основная (тёмно-синяя), контурная, светлая (на тёмной полосе). Высота ≥ 44 px. Одна подпись на действие:
  «Начать работу», «Отправить заявку», «Войти в Кабинет».
- **Карточка-вход** (первый экран): белая, верхняя линия `--c-accent` 3 px, заголовок со стрелкой.
- **Мост** (главная): три колонки «Заказчик — RailTech — Партнёр», центральная тёмно-синяя.
- **Плитки партнёров:** название, страна, статус; кликабельные → статья о партнёре в «Новостях». Основание статуса не показываем.
- **Карточка новости:** обложка 16:10 (или плашка «Фото готовится»), тип и дата, заголовок.
- **FAQ:** `<details>`, работает без JS.

## Телефон (≤ 760 px): меньше прокрутки

На телефоне показываем только необходимое:
- первый экран: заголовок, одна строка подзаголовка, две кнопки-входа без описаний; круговая графика скрыта;
- мост: только колонка RailTech по четырём этапам; описание барьеров — под «Подробнее» (`<details>`);
- возможности: компактный список (название + одна строка);
- о компании: один абзац и цифры 2×2;
- партнёры и новости: горизонтальная лента с прокруткой пальцем вместо столбика;
- Кабинет: без иллюстрации интерфейса, три факта в строку;
- заявка: только поля формы; контакты — одной строкой ссылок;
- футер: две колонки ссылок, без описания.

## Доступность (WCAG 2.2 AA)

Контраст текста ≥ 4,5:1; видимый фокус (`:focus-visible`, обводка `--c-brand-ink` 2 px со смещением); ссылка «Перейти к
содержимому»; поля формы с `<label>`; сообщения формы в `aria-live`; цели нажатия ≥ 44 px; без автопрокрутки и анимаций,
которые нельзя остановить; `prefers-reduced-motion` отключает переходы; декоративные изображения — `alt=""`/`aria-hidden`.
