   **Основание дилерского статуса не показываем** (только по запросу клиента).
5. **Без привязки к отрасли:** никаких «ж/д», названий и типов локомотивов в общих текстах.
6. **RU-first:** сейчас только русский. Перевод на EN и UZ — одним проходом **после** того, как владелец
   примет русскую версию и сам переключит `ruOnly: false` (`src/data/content-stage.json`).
7. Цифры на главной владелец правит сам в CMS → «Компания» → metrics.
8. Заявки с сайта уходят лидом в CRM платформы (`leadEndpoint` в `src/data/cms/company.json`), дальше работа в Кабинете.
   Персональные данные обрабатываются в CRM и Кабинете на серверах в Узбекистане.
9. Контакты: офис ул. Абдуллы Каххара, 46; на сайте только ИНН (без ОКЭД); почта info@; бот `railtech_test_bot`

10. Мобильная версия — без лишнего вертикального скролла (сейчас главная ≈ 7 экранов).

## 6. Живой запуск на своём компьютере

Нужны Node 22, Git, `make` (на Windows — Git Bash/WSL или команды `npm run …` из `package.json`).

```bash
git clone https://github.com/nzulkaynarov/rt-corporate-website.git
cd rt-corporate-website
git checkout claude/vibrant-allen-6fz8a6
make install            # npm ci
make dev                # http://localhost:4321/rt-corporate-website/ — правки видны сразу
```

- **Админка локально:** `http://localhost:4321/rt-corporate-website/admin/` → в Chrome или Edge выбрать
  «Work with Local Repository» и указать папку репозитория. Правки пишутся прямо в файлы, `make dev` их сразу показывает.
  Сервер `decap-server` не нужен.
- **Проверки:** `make check`. Браузерные тесты: один раз `npx playwright install chromium`, затем `make e2e`.
- **Предпросмотр сборки как на хостинге:** `make build && npx astro preview`.
- Как в Claude Code передать работу дальше: начни с `CLAUDE.md` → `docs/STATUS.md` (этот файл) → `docs/ARCHITECTURE.md`.
