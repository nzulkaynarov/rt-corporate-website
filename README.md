# RailTech v2.0 — Brutalist CAD Console Portal (railtech.uz)

Официальный многопрофильный B2B/B2G веб-портал **ООО «RailTech»** (Ташкент, Республика Узбекистан).

## Ключевые особенности
1. **Эстетика Brutalist CAD / Technical Wireframe (`END IS UI`)**: Матовое титаново-серое полотно (`#D4D8DC`), векторные линии 1px (`#0A0A0A`), изометрическая сетка и швейцарская типографика.
2. **4 динамических режима работы компании**:
   - `.SUPPLY`: Складская программа ЖД и промышленного оборудования в Ташкенте (комплекс Index, B2-2097).
   - `.CONTRACT`: Контрактные поставки ВЭД под ключ и проектный сорсинг для заводов и девелоперов.
   - `.DIGITAL`: Собственные IT-продукты (`b2b.railtech.uz`, `Smart Match AI`) и заказная разработка ПО.
   - `.PROJECTS`: Локализация производства, трансфер технологий и арт-инициативы (живопись, выставки).
3. **Процедурный 3D-движок на Three.js (`WireframeViewport.tsx`)**: Генерирует каркасные 3D-модели без тяжелых внешних файлов, работает на 60-120 FPS.
4. **Живой калькулятор Landed Cost (DDP Ташкент)**: Расчет стоимости поставки с учетом таможенных пошлин и НДС 12% РУз.
5. **Бесплатный хостинг на GitHub Pages**: Автоматический деплой через `.github/workflows/deploy.yml` с сохранением домена `railtech.uz`.

## Быстрый старт в Antigravity
```bash
npm install
npm run dev
```

Для мгновенного предпросмотра без установки пакетов откройте файл `preview-standalone.html` в любом браузере.
